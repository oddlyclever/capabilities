# Architecture Decision Records

One hard-to-reverse choice per record, numbered `ADR-0001` onward: a dependency picked over its alternatives, a public API shape, a target dropped from a module, an approach abandoned after it failed. Each says what forced the choice, what was chosen and why the alternatives lost. The decision itself is append-only, so reversing one takes a new record that supersedes it; the prose around it is corrected in place. A choice still being weighed is research, not a decision.
